# SIGIL — Product Walkthrough (Urdu/English)

**Target:** https://sigil.12nexusbpo.com
**Audience:** designers, agency owners and founders in Pakistan — people who would
actually run a branding project. Bilingual, so narration code-switches the way
they really speak.
**Goal:** by the end, a viewer understands that SIGIL is a *ten-stage design
process* with a human deciding at every gate — not a prompt box that spits out logos.
**Format:** mp4, 1920×1080, window chrome + gradient background, pointer cursor.
**Voice:** Gemini TTS `Charon`, Roman-Urdu + English mix.

---

## The demo client — Meeras Estates

Invented for this walkthrough.

| | |
|---|---|
| **Name** | Meeras Estates (میراث — *inheritance, heritage*) |
| **Founded** | 2011, Lahore |
| **Founders** | Two brothers — Adnan (civil engineer) and Bilal (property lawyer) |
| **Origin** | In 2008 the family's ancestral farmland in Sheikhupura was taken by a forged transfer deed. They never got it back. They built the company so it would not happen to other families. |
| **What they do** | Residential plot and family-estate brokerage. Every listing goes through forensic title verification *before* it is listed. |
| **Line** | "Zameen nahi — yaqeen." (Not land. Certainty.) |
| **Audience** | First-time plot buyers; overseas Pakistanis buying remotely, who cannot check papers themselves |
| **Personality** | trustworthy, meticulous, rooted, protective, unflashy |
| **Must avoid** | skylines, glass towers, house outlines, roof shapes, keys, handshakes |
| **Used on** | plot signboards, document files, WhatsApp DP, app icon, stamps on paperwork |

This brief is deliberately rich: the "seal / verification / document" territory is
genuinely distinct from real-estate cliché, so the AI output has somewhere real to go.

## Pacing rules

- Typing scenes use `type` (the typing *is* the story) — everything else `fill`.
- Generation waits are sped up per-step (`speed: 3–6`) so the viewer sees progress
  without real-time waiting; the narration covers the gap.
- Each scene's on-screen time must be ≥ its narration clip; measured after TTS,
  pacing tuned before the final render.
